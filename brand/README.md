# FLOW logo

**Idea:** an F built from the game's own parts: a column of board cells as the stem, and two pods (capsules) as the
arms. The cells are cyan and the pods are magenta, matching how plasma moves from the board into the pods.

Everything here is generated by `brand/build_logo.py`. Change the geometry or colours there and re-run it
(`python3 brand/build_logo.py` from the repo root, needs `rsvg-convert`); don't edit the SVGs by hand.

## Files

| File | Use |
|---|---|
| `svg/flow-horizontal-<scheme>.svg` | Primary logo: symbol + wordmark side by side |
| `svg/flow-stacked-<scheme>.svg` | Symbol above wordmark, for square or tall spaces |
| `svg/flow-symbol-<scheme>.svg` | Symbol alone (256 canvas, optically centred) |
| `svg/flow-symbol-small-<scheme>.svg` | Simplified 3-row symbol for **32 px and below** (pixel-snapped at 16 px) |
| `svg/flow-wordmark-<scheme>.svg` | Wordmark alone |
| `svg/flow-app-icon.svg` | Neon app icon master (glow, backdrop, grid; uses SVG filters, so screens only) |
| `png/` | Ready-made PNG renders of the above |
| `public/favicon.ico`, `public/favicon.svg` | Browser tab icon (small symbol on a dark tile) |
| `public/apple-touch-icon.png` | iOS home screen (180 px, full-bleed; iOS rounds the corners) |
| `public/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | PWA / Android icons, referenced from `public/manifest.webmanifest` |

Schemes: `color` (on dark: the default), `color-light` (on light backgrounds), `white`, `black`, `cyan` (one colour).

## Colour

| Name | HEX | Role |
|---|---|---|
| Plasma Cyan | `#00f0ff` | Cells (stem). Same as the game palette's `cyan` |
| Pod Magenta | `#ff2bd6` | Pods (arms). Same as the game palette's `magenta` |
| Void | `#05030c` | Background, icon tiles. Same as `COLORS.bg` |
| Ink | `#e8f6ff` | Wordmark on dark. Same as `COLORS.text` |
| Cyan Deep | `#008aa6` | Cells on light backgrounds (4.0:1 on white) |
| Magenta Deep | `#c4009c` | Pods on light backgrounds (5.5:1 on white) |

Approved pairs: `color` on Void or any dark navy/purple · `color-light` on white · `white` on any dark or busy
background · `black` on white. Neon cyan on white is unreadable (1.4:1), so never put the `color` version on a light
background.

The neon glow is an effect for screens (app icon, title screens, trailers). The flat masters stay flat; don't bake
glows, shadows or outlines into them.

## Clear space and minimum size

- **Clear space:** one cell (the height of one stem square) on every side.
- **Minimum size:** horizontal logo 120 px wide; symbol 40 px tall. Below that, switch to `flow-symbol-small-*`,
  which holds down to 16 px.

## Wordmark

Squared geometric caps drawn as outlines to echo Orbitron, the in-game font. In the lockups the wordmark's cap
height equals two cells plus a gap, so it matches the height of the F's two arms. The wordmark has no font dependency.

## Don'ts

Don't recolour the cells and pods outside the palette, swap their colours, or make them the same colour in the
`color` scheme. Don't stretch, rotate, or rearrange the cells. Don't retype "FLOW" in a font in place of the wordmark.
Don't put the `color` version on light backgrounds.

## Notes

- Trademark: no clearance search has been done. Before any public launch, check the name and mark (the puzzle game
  *Flow Free* is the closest neighbour in the category).
